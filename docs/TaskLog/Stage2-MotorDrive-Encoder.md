## 2. 实现摘要

### 2.1 驱动结构

- `bsp_motor.c` 负责底层硬件访问：
  - `TB6612` 的 `AIN1/AIN2/BIN1/BIN2/STBY`
  - `TIMA0` 双路 PWM 占空比设置
  - 左轮 `TIMG8 QEI` 16-bit 计数扩展为 32-bit
  - 右轮 `PA12` 双边沿中断 + `PA13` 电平判方向
  - `S1(PA18)` 按键中断与去抖
- `app_motor_demo.c` 负责演示逻辑：
  - 上电后默认两轮同向运行，PWM = `350/1000`
  - 每按一次 `S1`，正转/反转翻转
  - 每 `100 ms` 打印左右轮累计计数与角度
  - 每 `250 ms` 翻转一次绿灯，作为循环心跳

### 2.2 编码器策略

当前实现沿用阶段 0 的资源结论：

- **左轮**：继续使用 `TIMG8` 硬件 QEI，分辨率按 `11 PPR * 30:1 * 4 = 1320 count/rev`
- **右轮**：使用 `PA12` 双边沿中断，`PA13` 只在 ISR 中读取电平判方向，分辨率按 `11 PPR * 30:1 * 2 = 660 count/rev`

这样做的好处：

- 左轮角度统计稳定，不怕高速漏脉冲
- 右轮 CPU 占用较低，适合现阶段先验证驱动链路
- 后续若右轮分辨率不够或高速丢计数，可再升级为 `A/B 双通道中断` 或 `CAPTURE` 模式

## 3. 关键接口说明

### 3.1 `bsp_motor_set_output(int16_t left_permille, int16_t right_permille)`

- 输入范围：`[-1000, 1000]`
- 正值：正转
- 负值：反转
- `0`：滑行停止

PWM 占空比采用千分比接口，而不是百分比，目的是给后续平衡环和速度环预留更细的分辨率。

### 3.2 `bsp_motor_update(void)`

建议在 `1 kHz` 周期内调用。当前由 `SysTick` 主循环每毫秒调用一次，职责是：

- 读取左轮 `QEI` 计数
- 处理 16-bit 环绕
- 更新左右轮角度值

### 3.3 `bsp_motor_consume_toggle_request(void)`

- 来源：`GPIOA_IRQHandler()` 中 `S1(PA18)` 中断
- 作用：把“按键触发”从 ISR 传给主循环，避免在中断里直接改 PWM

## 5. 串口日志格式

日志由板载 `UART0(XDS-UART)` 输出，波特率保持 `115200 8N1`。

上电后会看到：

```text
[boot] MSPM0G3507 stage2 motor driver start
[boot] stage2 motor demo start
[boot] press S1(PA18) to toggle motor direction
```

运行中每 `100 ms` 输出：

```text
[enc] t=1200ms L=158(43.09 deg) R=82(44.73 deg)
```

按下 `S1` 后输出：

```text
[motor] dir=reverse pwm=350/1000
```

说明：

- `L` / `R` 是累计计数，不会自动清零
- `deg` 是基于编码器参数换算出的输出轴机械角
- 若正反方向和你的实物相反，可在 `bsp_motor.c` 顶部调整 `BSP_MOTOR_LEFT_SIGN`、`BSP_MOTOR_RIGHT_SIGN`

## 6. 验收建议

本轮建议按下面顺序验证：

1. **空载验方向**
   - 先断开车轮离地
   - 上电后观察两轮是否同向旋转
   - 按下 `S1`，两轮应整体反向
2. **验编码器计数**
   - 用手慢慢拨动左轮，日志中的 `L` 应连续变化
   - 用手慢慢拨动右轮，日志中的 `R` 应连续变化
   - 反向拨动时计数应反向变化
3. **验角度换算**
   - 在轮胎上做一个明显标记
   - 手动转约 1 圈，观察日志角度是否接近 `360 deg`
   - 如果明显偏差，优先检查 `减速比` 与 `PPR` 宏是否和实物一致
4. **验按键去抖**
   - 快速连按 `S1`
   - 方向切换不应抖动或一次按下切两次

## 7. 接线指导

### 7.1 TB6612 与 MSPM0G3507

| TB6612 引脚 | MSPM0G3507 引脚 | 说明                    |
| --------- | ------------- | --------------------- |
| `PWMA`    | `PA8`         | 左电机 PWM               |
| `AIN1`    | `PA15`        | 左电机方向 1               |
| `AIN2`    | `PA16`        | 左电机方向 2               |
| `PWMB`    | `PA9`         | 右电机 PWM               |
| `BIN1`    | `PA26`        | 右电机方向 1               |
| `BIN2`    | `PA27`        | 右电机方向 2               |
| `STBY`    | `PB0`         | 使能脚，高电平工作             |
| `VCC`     | `5V` 或驱动板逻辑电源 | 逻辑电源，按你板卡要求接          |
| `VM`      | 电机独立电源        | 电机供电，不可直接拿 MCU 3V3 代替 |
| `GND`     | `GND`         | 必须与主控共地               |
| `AO1/AO2` | 左 GB370 两根电机线 | 左电机功率输出               |
| `BO1/BO2` | 右 GB370 两根电机线 | 右电机功率输出               |

### 7.2 左电机编码器

| 编码器引脚     | MSPM0G3507 引脚 | 说明           |
| --------- | ------------- | ------------ |
| `A`       | `PA29`        | `TIMG8_CCP0` |
| `B`       | `PA30`        | `TIMG8_CCP1` |
| `Z/Index` | `PB14`        | 若电机无此脚可不接    |
| `VCC`     | `3V3`         | 先确认编码器模块电压等级 |
| `GND`     | `GND`         | 与主控共地        |

### 7.3 右电机编码器

| 编码器引脚 | MSPM0G3507 引脚 | 说明           |
| ----- | ------------- | ------------ |
| `A`   | `PA12`        | 双边沿中断输入      |
| `B`   | `PA13`        | ISR 内读电平判方向  |
| `VCC` | `3V3`         | 先确认编码器模块电压等级 |
| `GND` | `GND`         | 与主控共地        |

### 7.4 板载资源

| 资源               | 引脚          | 用途      |
| ---------------- | ----------- | ------- |
| `S1`             | `PA18`      | 切换电机正反转 |
| `XDS-UART TX/RX` | `PA10/PA11` | 调试日志口   |
| `LED_G`          | `PB27`      | 主循环心跳   |
| `LED_B`          | `PB22`      | 方向切换提示  |

### 7.5 接线注意事项

- 编码器 `VCC` 请先确认是 `3.3 V` 还是 `5 V` 版本，不确定前不要直接接主控 IO。
- TB6612 的 `VM` 与主控逻辑电源分开供电，但 **GND 必须共地**。
- 初次上电务必让车轮离地，确认方向正确后再落地测试。
- 若某个电机方向与日志方向相反，优先交换该电机两根动力线，或调整 `AIN/BIN` 真值表。
- 若编码器角度方向相反，优先调整 `BSP_MOTOR_LEFT_SIGN` / `BSP_MOTOR_RIGHT_SIGN`，不要直接改业务层公式。

## 8. 后续建议

- 下一步可在 `bsp_motor` 上层叠加轮速计算（`count delta / dt`），形成速度闭环输入。
- 若需要更高的右轮角度分辨率，可把右轮从当前 `X2` 升级到 `A/B 双边沿 X4` 解码。
- 进入平衡车阶段前，建议增加“跌倒时自动拉低 `STBY`”的保护逻辑。
