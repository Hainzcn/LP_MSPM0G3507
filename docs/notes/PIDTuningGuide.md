# 平衡车 PID 调参指南（四级级联版）

本文面向当前工程的四级级联多速率控制架构。核心代码在 `template/app/app_balance.c`，底层电机在 `template/hardware/bsp_motor.c`，安全保护在 `template/app/app_safety.c`。

## 1. 控制结构概览

装车模式默认由 `main.c` 启动，串口发送 `t` / `test` 进入电机演示模式，`l` / `load` 返回。

控制环从内到外依次为：

```
速度环 (20 Hz) ─→ 角度环 (100 Hz) ─→ 角速度环 (200 Hz) ─→ 电机输出 (200 Hz)
航向环 (50 Hz) ──────────────────────→ 差分叠加 ─────────┘
```

| 环路 | 频率 | 输入 | 输出 | 串口命令 |
|------|------|------|------|----------|
| 角速度环 | 200 Hz | 目标角速率 − 实测角速率 (°/s) | PWM permille | `rp` |
| 角度环 | 100 Hz | 目标倾角 − 实测 pitch (°) | 目标角速率 (°/s) | `bp` |
| 速度环 | 20 Hz | 目标速度 − 实测速度 (cps) | 目标倾角 (°) | `sp` |
| 航向环 | 50 Hz | 偏航误差 (°) | 差分 PWM permille | `yp` |

底层补偿已在 BSP 处理：右路正转 ×0.98 系数、四方向静/动摩擦死区。调 PID 时无需手动补偿。

## 2. 调参前检查

### 硬件方向确认

1. 串口发送 `t` 进入 demo 模式，`r` 启动、`b` 急刹、`+`/`-` 调速。
2. 同向运行时 `rpmL` 与 `rpmR` 应同号。

### 姿态方向确认

- `APP_BALANCE_PITCH_INVERT=1`：已对 MS901M 安装方向做软件翻转。
- 手扶车体前倾时，日志 `pitch` 应为正值（偏离平衡点的方向）。
- 如果方向相反，先调 `APP_BALANCE_PITCH_INVERT`，不要动 PID。

### 安全须知

- `app_safety` 在跌倒和低电压时自动切断输出，不要绕过。
- 上电后 `APP_SAFETY_STARTUP_FALL_MUTE_MS` 默认静默 2500 ms，期间不判跌倒、不输出 PID。
- 红灯常亮 = FALLEN 或 LOW_BAT_STOP，看 `[hb] state=... batt=...` 区分。
- 初期建议把 `APP_BALANCE_MAX_PWM_PERMILLE` 临时降到 300~500，确认方向后再放开。

## 3. 串口命令格式

所有增益以 ×1000 定点整数输入，避免每次改代码重新编译：

```text
rp <kp_x1000> <ki_x1000> <kd_x1000>   # 角速度内环 (200 Hz)
bp <kp_x1000> <ki_x1000> <kd_x1000>   # 角度环 (100 Hz)
sp <kp_x1000> <ki_x1000> <kd_x1000>   # 速度外环 (20 Hz)
yp <kp_x1000> <ki_x1000> <kd_x1000>   # 航向环 (50 Hz)
pid?                                   # 查询全部参数
pid0                                   # 四路 PID 全部清零
yi0 / yi1                              # Yaw 极性翻转 关/开
```

例：`rp 1500 0 0` → 角速度环 Kp=1.500，`bp 10000 0 0` → 角度环 Kp=10.000。

## 4. 推荐调参顺序与参考值

**原则：从最内环开始，逐层向外。每次只改一个参数。**

### 4.1 第一步：角速度内环 (`rp`，200 Hz)

功能：将角度环输出的"目标角速率"跟踪到实际陀螺仪角速率上，输出 PWM。这是对干扰响应最快的环路。

先把所有外环清零：

```text
pid0
```

然后只设角速度环：

```text
rp 1500 0 0
```

手扶车体，缓慢前后倾倒，观察电机是否跟随阻尼。

| 参数 | 参考范围 | 起步值 | 说明 |
|------|----------|--------|------|
| Kp | 0.5 ~ 5.0 | **1.5** | 角速率误差 (°/s) → PWM (‰)。太小无力，太大高频抖动 |
| Ki | 0 | **0** | 角速度环不需要积分，纯 PD 即可 |
| Kd | 0 ~ 0.05 | **0** | 角加速度阻尼，通常不需要；加大容易放大噪声 |

判断标准：
- 手推时有明显阻尼感，松手后不自由落下 → Kp 合适
- 电机嗡嗡高频抖 → Kp 偏大，降低
- 完全没反应 → Kp 太小

### 4.2 第二步：角度环 (`bp`，100 Hz)

功能：将速度环输出的"目标倾角"跟踪到实际俯仰角上，输出"目标角速率"给角速度环。

保持角速度环不变，设角度环：

```text
bp 10000 0 0
```

此时速度环仍为 0，`target_tilt_deg = 0`，角度环仅负责让车"站在零度附近"。

| 参数 | 参考范围 | 起步值 | 说明 |
|------|----------|--------|------|
| Kp | 5.0 ~ 25.0 | **10.0** | 倾角误差 (°) → 目标角速率 (°/s)。决定平衡刚度 |
| Ki | 0 ~ 3.0 | **0** | 消除稳态角度偏差，初期不加 |
| Kd | 0 | **0** | 角速度环已提供微分作用，此处无需 D 项 |

判断标准：
- 手扶倾倒后车能追着倾倒方向跑 → 方向正确，Kp 初步合适
- 追着跑但越追越猛、来回晃 → Kp 偏大，或角速度环 Kp 不足
- 松手后缓慢倒下 → Kp 偏小
- 能短暂站立 3~5 秒 → 可以进入下一步

### 4.3 第三步：速度外环 (`sp`，20 Hz)

功能：让车不会持续向一个方向漂走。输出"目标倾角"给角度环。

内环已稳后设速度环：

```text
sp 3 1 0
```

| 参数 | 参考范围 | 起步值 | 说明 |
|------|----------|--------|------|
| Kp | 0.001 ~ 0.02 | **0.003** | 速度误差 (cps) → 目标倾角 (°)。量纲差距大，数值很小 |
| Ki | 0 ~ 0.005 | **0.001** | 消除稳态速度漂移，不可过大 |
| Kd | 0 | **0** | 编码器差分噪声大，D 项容易放大跳变 |

判断标准：
- 车站稳但缓慢漂走 → Kp 偏小
- 前后大幅低频摇摆（周期 > 1 秒）→ Kp 偏大，与内环耦合
- 站稳且不漂 → 成功

速度环输出被限幅到 ±`APP_BALANCE_MAX_TILT_DEG`（默认 10°），初期不要加大。

### 4.4 第四步：航向环 (`yp`，50 Hz)

功能：直行时锁定航向，抑制原地偏航。输出差分 PWM 叠加到左右轮。

```text
yp 800 0 200
```

| 参数 | 参考范围 | 起步值 | 说明 |
|------|----------|--------|------|
| Kp | 0.3 ~ 3.0 | **0.8** | 偏航误差 (°) → 差分 PWM (‰) |
| Ki | 0 ~ 0.5 | **0** | 航向积分通常不需要 |
| Kd | 0.05 ~ 0.5 | **0.2** | 偏航角速率阻尼 |

航向环输出被限幅到 ±`APP_BALANCE_YAW_MAX_CORRECTION_PM`（默认 200‰），防止航向修正扰动平衡。

## 5. 参考参数一览

以下为建议起步值，需根据实车调整：

```text
# 角速度内环 (200 Hz)  — 先调
rp 1500 0 0

# 角度环 (100 Hz)      — 第二调
bp 10000 0 0

# 速度外环 (20 Hz)     — 站稳后调
sp 3 1 0

# 航向环 (50 Hz)       — 最后调
yp 800 0 200
```

等效实际值：

| 环路 | Kp | Ki | Kd |
|------|-----|-----|-----|
| 角速度 (`rp`) | 1.500 | 0 | 0 |
| 角度 (`bp`) | 10.000 | 0 | 0 |
| 速度 (`sp`) | 0.003 | 0.001 | 0 |
| 航向 (`yp`) | 0.800 | 0 | 0.200 |

## 6. 常见现象对照

| 现象 | 优先检查 | 处理建议 |
|------|----------|----------|
| 前倾时车后退 | pitch 翻转、电机极性 | 先修方向，不调 PID |
| 一上电猛冲 | 角度环 Kp 过大、pitch offset 错 | 降 Kp，确认 pitch 零点 |
| 高频抖动、电机嗡嗡响 | 角速度环 Kp 过大 | 降 `rp` Kp |
| 低频前后晃（周期 > 1s） | 速度环 Kp 偏大 | 先关速度环，只调内环 |
| 车能站但一直慢走 | pitch offset、速度环 Kp/Ki | 先校零点，再微调速度环 |
| 松手后缓慢倒下 | 角度环 Kp 偏小 | 加大 `bp` Kp |
| 直行偏一边 | 航向环增益、硬件摩擦差 | 先开航向环，看 `yawErr`/`yawCorr` |
| 跌倒后不重启 | `app_safety` 状态 | 需重新 arm，低压 STOP 不能自动恢复 |

## 8. 调参策略总结

1. `pid0` 全部清零，用 demo (`t`) 复测电机方向和编码器。
2. 确认 pitch 方向和零点。
3. **只开角速度环** (`rp`)：从 Kp=1.0 起步，手推有阻尼感即可。
4. **叠加角度环** (`bp`)：从 Kp=8.0 起步，手扶能短暂站立。
5. **叠加速度环** (`sp`)：站稳后从 Kp=0.002 起步，消除漂移。
6. **叠加航向环** (`yp`)：最后开启，锁定直行方向。

先让车"方向正确、阻尼可控"，再追求"站得久、走得直"。
