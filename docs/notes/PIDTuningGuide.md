# 平衡车 PID 调参指南

本文按当前工程状态编写，面向第一次搭建两轮平衡车的调试过程。核心代码在 `template/app/app_balance.c`，底层电机输出在 `template/hardware/bsp_motor.c`，安全保护在 `template/app/app_safety.c`。

## 1. 当前工程的控制结构

装车模式默认由 `main.c` 启动，串口发送 `t` / `test` 才进入电机演示模式；其中 `t` 单字符立即生效，`test` 兼容回车。在电机演示模式发送 `l` / `load` 返回装车模式。

装车模式使用两级 PID：

1. 速度外环 `speed_pid`：输入目标速度 `target_speed_cps` 与左右轮平均速度，输出目标车体倾角 `target_tilt_deg`。
2. 平衡内环 `balance_pid`：输入目标倾角与实际 pitch，输出基础 PWM `pwm_out`。
3. 转向与同步叠加：`target_yaw_pm` 用于差速转向；直行时 `balance_sync_step()` 根据左右轮速度差增加小幅差分补偿。
4. 底层电机补偿：`bsp_motor` 已固定对右路正向命令乘 `BSP_MOTOR_RIGHT_FORWARD_SCALE_X1000=950`，用于抵消右路正转约快 5% 的硬件偏差；同时 `BSP_MOTOR_DEADZONE_COMP_PM=50` 会把非零逻辑 PWM 抬升到起转死区以上。

因此，调 PID 时不要再人为给右轮额外减 5%，也不要在 PID 输出里额外叠加死区补偿。如果左右轮直行仍有残差，优先看同步环诊断 `syncErr` / `syncCorr`，不要把轮速偏差硬塞进平衡 PID。

## 2. 调参前检查

先用电机演示模式确认硬件方向和编码器方向：

- 装车模式下串口发送 `t` 或 `test` 进入 demo。
- 发送 `r` 启动、`b` 急刹、`+` / `-` 调速。
- 观察 `[enc]` 日志：同向运行时 `rpmL` 与 `rpmR` 应同号，差值应比未补偿时明显缩小。
- 发送 `p` 查看同步诊断，稳定时 `err` 和 `corr` 不应长期贴近限幅。

再确认姿态方向：

- 当前 `APP_BALANCE_PITCH_INVERT=1`，说明 MS901M 前后方向按已发现的实车安装方式做了软件翻转。
- 平衡层默认启用 `APP_BALANCE_PITCH_LPF_ALPHA=0.35f` 一阶低通。若日志 pitch 高频抖动明显，可适当降低到 `0.20~0.30`；若车体响应明显变慢，可提高到 `0.45~0.60`。
- 手扶车体前倾时，日志里的 `pitch` 应按项目定义朝“需要电机向前追车”的方向变化。
- 如果前倾仍然后退，先调整 `APP_BALANCE_PITCH_INVERT` 或运行时调用 `app_balance_set_pitch_inverted()`，不要先调 PID。

安全检查：

- 车轮悬空时可以做方向测试，但真正调平衡必须双手扶车、轮子接触地面。
- `app_safety` 会在跌倒和低电压时切断输出；调参时不要绕过它。
- 主入口最多等待 3000 ms 获取 MS901M 第一帧姿态；进入装车模式后，`APP_SAFETY_STARTUP_FALL_MUTE_MS` 默认再静默 2500 ms 等待姿态稳定，这段时间不判跌倒，也不输出 PID。
- 跌倒需要连续 5 个控制拍确认，低压急停需要连续 20 个电池采样确认；红灯常亮通常表示 `FALLEN` 或 `LOW_BAT_STOP`，可先看 1 Hz `[hb] state=... batt=...` 日志区分原因。
- 初期建议把 `APP_BALANCE_MAX_PWM_PERMILLE` 或 BSP PWM limit 临时降到 300~500，确认方向正确后再逐步放开。

## 3. 推荐调参顺序

装车模式的 PID 通过 XDS-UART 注入，输入格式统一为 x1000 定点整数，避免每次改 `main.c` 后重新编译：

```text
bp <kp_x1000> <ki_x1000> <kd_x1000>   # 平衡内环
sp <kp_x1000> <ki_x1000> <kd_x1000>   # 速度外环
pid?                                  # 查询当前参数
pid0                                  # 两路 PID 清零
```

例如 `bp 8000 0 1000` 表示平衡环 `Kp=8.000 Ki=0 Kd=1.000`，`sp 2 0 0` 表示速度环 `Kp=0.002 Ki=0 Kd=0`。

### 3.1 先只调平衡内环

第一阶段先让车“能被手扶着站住”，不要追求定点不漂。

建议先通过串口把速度环清零：

```text
sp 0 0 0
```

此时 `target_tilt_deg` 基本为 0，只调平衡环，例如从 `bp 4000 0 0` 开始逐步增加。

步骤：

1. `Ki=0`，`Kd=0`，从很小的 `Kp` 开始。
2. 手扶车体，轻轻前后推。如果车完全不反抗，逐步加大 `Kp`。
3. 当车能明显“追着倾倒方向跑”，说明方向正确。
4. 如果刚一倾斜就猛冲、抖动或尖叫，`Kp` 太大，先降下来。
5. 在合适的 `Kp` 基础上加 `Kd`，让它不再来回摆。`Kd` 的作用是阻尼，太大会放大姿态噪声，让电机发抖。
6. 平衡内环初期不要加 `Ki`。平衡车内环通常先靠 P/D 站住，I 项容易在扶车和跌倒时积累，导致突然冲车。

经验判断：

- 前倾时车后退：姿态方向或电机方向错，不是 PID 大小问题。
- 车会追，但越追越过头：`Kp` 偏大或 `Kd` 不够。
- 车软、倒得慢但不追：`Kp` 偏小。
- 高频抖动、电机嗡嗡响：`Kd` 偏大或姿态噪声太大。

### 3.2 再调速度外环

平衡内环能在手扶下稳定后，再打开速度外环。速度环负责“让车别一直跑走”，它的输出是目标倾角，不直接输出 PWM。

建议从：

```text
sp 2 0 0
```

开始，`Ki` 和 `Kd` 先保持 0。

步骤：

1. 目标速度保持 0。
2. 如果车能站住但缓慢漂走，逐步增加 `Kp_speed`。
3. 速度环 `Kp` 太小，车会一直漂；太大，车会前后低频摇摆。
4. 只有当长期有固定方向慢漂，且机械重心和 pitch offset 已确认后，再加很小的 `Ki_speed`。
5. 速度环 `Kd` 通常最后再考虑，因为编码器速度是 20 ms 差分得到的，低速分辨率有限，D 项容易放大跳变。

速度环输出有限幅 `APP_BALANCE_MAX_TILT_DEG`，默认 10 度。初期不要把这个值调大；车还没稳时，大目标倾角只会让它更容易冲出去。

### 3.3 最后处理直行同步和转向

当前装车模式已启用直行双轮同步：

- `APP_BALANCE_SYNC_ENABLED=1`
- `APP_BALANCE_SYNC_KP_PM_PER_CPS_X100=20`
- `APP_BALANCE_SYNC_KI_PM_PER_CPS_STEP_X100=0`
- `APP_BALANCE_SYNC_MAX_CORRECTION_PM=200`
- `APP_BALANCE_SYNC_MIN_DRIVE_PM=30`

同步环只在 `target_yaw_pm==0` 且平衡输出超过 `APP_BALANCE_SYNC_MIN_DRIVE_PM` 时工作。PID 输出接近 0 或手动拨轮时会暂停同步；平衡环真正发力时，即使目标速度为 0，也会恢复同步以抑制原地打转。

调法：

1. 平衡和速度环没稳前，不要急着调同步环。
2. 若直行时长期偏向一边，先看 `syncErr` 和 `syncCorr`。
3. `syncCorr` 长期很大但仍偏，可能是机械摩擦、轮胎半径、编码器安装或电机线序问题。
4. 出现左右轮互相拉扯、蛇形摆动，先降低 `APP_BALANCE_SYNC_KP_PM_PER_CPS_X100`。
5. 积分项默认 0 是合理的；只有确认存在稳定残差且不会和速度环互相打架时，再极小幅打开同步积分。

## 4. 参数记录模板

每次只改一个参数，并记录现象。建议按下面格式写到任务日志或单独记录文件：

```text
日期/电池电压：
机械状态：轮胎/重心/IMU安装/电池位置
Pitch invert：
Balance PID：Kp=  Ki=  Kd=
Speed PID：Kp=  Ki=  Kd=
Sync：Kp_x100=  Ki_x100=  max=
现象：
下一步：
```

不要凭感觉一次改三四个参数。平衡车的现象很容易混在一起，单变量记录能最快定位问题。

## 5. 常见现象对照

| 现象 | 优先检查 | 处理建议 |
| --- | --- | --- |
| 前倾时车后退 | pitch 翻转、电机极性、编码器符号 | 先修方向，不调 PID |
| 一上电猛冲 | Kp 过大、pitch offset 错、目标倾角非 0 | 降 Kp，确认 pitch 零点 |
| 低频前后晃 | 速度环 Kp 偏大或平衡 Kd 不够 | 先关速度环，只调内环 |
| 高频抖动 | Kd 过大、姿态噪声、机械松动 | 降 Kd，检查 IMU 固定 |
| 车能站但一直慢走 | pitch offset、重心、速度环 Kp/Ki | 先校零点，再微调速度环 |
| 直行偏一边 | 右路补偿、同步环、轮胎/摩擦 | 看 `syncErr/syncCorr`，不要改平衡 PID |
| 跌倒后不重新启动 | `app_safety` 状态 | 需要重新 arm，低压 STOP 不能自动恢复 |

## 6. 建议起步策略

本项目现在已经具备比较好的调参基础：默认进装车模式，demo 可随时用 `t/test` 进入，右路 5% 基础偏差在 BSP 统一处理，pitch 翻转和双轮同步也已接入。接下来最稳妥的路线是：

1. 用 demo 复测左右轮方向、速度、急刹。
2. 固定 IMU 和电池，确认 pitch 零点。
3. 速度环全 0，只调平衡内环 P/D。
4. 能手扶站住后，再打开速度外环 P。
5. 只有在站稳和慢速不漂后，再处理同步环和转向。

先让车“方向正确、反应可控”，再追求“站得久、走得直”。这会比一开始追求完整自动平衡更安全，也更容易判断每个参数的作用。
