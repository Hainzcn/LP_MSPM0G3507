# MSPM0G3507 自平衡小车项目架构与原理解析

本文档为初学者提供一个清晰易懂的项目纵览，帮助你快速理解这台自平衡瞄准小车是如何组织和工作的。

## 1. 整体分层架构

整个项目代码按照“底层 -> 中间层 -> 应用层”的结构组织，这种结构让代码职责分明，就像盖房子一样：

- **硬件驱动层 (Hardware/BSP)**：直接和单片机（MCU）的引脚打交道。比如控制电机转动、读取传感器数据、点亮 LED 灯等。
- **中间件层 (Middle)**：提供一些通用的算法或工具，它们不依赖于具体的硬件引脚。比如 PID 控制算法、传感器数据解析逻辑。
- **应用逻辑层 (App)**：真正实现“小车功能”的地方。比如什么时候该刹车、怎么保持平衡、按键按下的逻辑。
- **程序入口 (`main.c`)**：把上面所有部分组装起来，开机后按照顺序初始化，并进入小车的主循环。

## 2. 核心功能与模块解析

### 2.1 硬件驱动 (BSP - Board Support Package)
- **`bsp_motor.c` (电机与编码器)**：负责给电机驱动芯片（TB6612）发送 PWM 信号（控制转速和方向），同时通过读取车轮上的编码器脉冲，计算出小车当前的速度和走了多远。
- **`bsp_imu_uart.c` & `bsp_k230_uart.c` (串口通信)**：小车用串口和外界沟通。`bsp_imu_uart` 负责接收 MS901M 姿态传感器的角度数据；`bsp_k230_uart` 负责接收 K230 视觉模块的指令。
- **`bsp_battery.c` (电池监测)**：通过 ADC（模数转换器）时刻测量电池电压，防止电池过放电损坏。

### 2.2 中间层 (Middleware)
- **`ms901m.c` (姿态解析)**：将传感器发来的一串串“0101”的原始字节数据，翻译成小车当前的俯仰角（Pitch）、翻滚角（Roll）等人类能看懂的角度数据。
- **`pid.c` (PID 控制器)**：自动控制的核心算法。简单来说，就是根据“我想达到的目标”和“现在的实际情况”之间的偏差，计算出“我应该出多大点力”。

### 2.3 应用逻辑 (App)
- **`app_safety.c` (安全管家)**：小车的“保命系统”。它会一直盯着电池电压和小车倾角，如果电压太低（`LOW_BAT_STOP`）或者小车摔倒了（`FALLEN`），它会立刻切断电机动力，防止危险发生。按下板子上的 S1 按键可以重新启动（Arm）或急停（Disarm）。
- **`app_balance.c` (平衡大脑)**：控制小车不倒的核心。它包含了小车的主循环调度，并运用了“串级 PID”（下面会详细讲）来计算电机该怎么转。
- **`app_motor_demo.c` (电机测试)**：一个独立的测试模式，可以在不开启平衡功能的情况下，通过串口发送指令来测试电机转动是否正常。

## 3. 小车是如何运转的？（调度机制）

小车没有使用复杂的操作系统（RTOS），而是用了一个简单高效的“时间片轮询”机制（核心代码在 `app_balance.c` 的 `app_balance_run` 函数中）：
单片机里有一个滴答定时器（SysTick），每 **1 毫秒 (1 ms)** 产生一次心跳，小车就根据这个心跳来安排工作：

- **每 1 毫秒 (1000 Hz)**：读取最新的传感器数据缓存，更新电机编码器脉冲计数。
- **每 10 毫秒 (100 Hz)**：**核心控制时刻**。检查电池电压，读取当前姿态，并执行一次 PID 平衡计算，把计算出的动力下发给电机。
- **每 200 毫秒 (5 Hz)**：闪烁一次绿灯，代表小车还活着（心跳指示）；如果遇到低压或摔倒等危险，亮起红灯警告。
- **每 1000 毫秒 (1 Hz)**：通过串口往电脑打印一行当前的状态数据（角度、速度、电池等），方便开发者肉眼观察和调试。

## 4. 平衡控制是怎么实现的？（串级 PID）

小车要实现既能站稳，又能听话地往前走，用到了“串级 PID”（即两个 PID 嵌套在一起）：

1. **外环：速度环 (Speed PID)**
   - **输入**：你想让小车跑多快（目标速度）对比小车现在的真实速度。
   - **思考过程**：如果我走得太慢，我就应该往前倾斜一点来利用重力加速。
   - **输出**：计算出一个“目标倾斜角度”。
2. **内环：平衡环 (Balance PID)**
   - **输入**：外环给出的“目标倾斜角度”对比传感器测量出的真实倾斜角度。
   - **思考过程**：我现在的角度和目标角度有偏差，我需要让车轮转动来纠正这个角度，防止摔倒。
   - **输出**：最终输出给电机的动力大小（PWM 值）。

**简单总结**：速度环告诉小车“你应该倾斜多少度来走路”，平衡环告诉电机“赶紧转，保持住这个倾斜度别摔了”。
