# MSPM0G3507 自平衡小车项目架构与原理解析

本文档为初学者提供一个清晰易懂的项目纵览，帮助你快速理解这台自平衡瞄准小车是如何组织和工作的。

## 1. 整体分层架构

整个项目代码按照"底层 -> 中间层 -> 应用层"的结构组织，这种结构让代码职责分明，就像盖房子一样：

- **硬件驱动层 (Hardware/BSP)**：直接和单片机（MCU）的引脚打交道。比如控制电机转动、读取传感器数据、点亮 LED 灯等。
- **中间件层 (Middle)**：提供一些通用的算法或工具，它们不依赖于具体的硬件引脚。比如 `pid2_t` 控制算法、传感器数据解析逻辑、K230 通讯协议、车体运动学换算。
- **应用逻辑层 (App)**：真正实现"小车功能"的地方。比如平衡控制、安全保护、圆弧运动演示、电机测试。
- **程序入口 (`main.c`)**：把上面所有部分组装起来，开机后按照顺序初始化，并进入小车的主循环。

## 2. 核心功能与模块解析

### 2.1 硬件驱动 (BSP)
- **`bsp_motor.c` (电机与编码器)**：负责给电机驱动芯片（TB6612）发送 PWM 信号，同时通过车轮编码器计算当前速度和里程。
- **`bsp_imu_uart.c` & `bsp_k230_uart.c` (串口通信)**：`bsp_imu_uart` 接收 MS901M 姿态传感器的角度数据（FIFO 中断 + 环缓）；`bsp_k230_uart` 与 K230 视觉模块通信（**FIFO 半满中断** 驱动，非 DMA）。
- **`bsp_battery.c` (电池监测)**：通过 ADC 时刻测量电池电压，防止过放电。

### 2.2 中间层 (Middleware)
- **`ms901m.c` (姿态解析)**：将传感器发来的二进制字节流翻译成俯仰角（Pitch）、翻滚角（Roll）等角度数据。
- **`pid.c` (PID 控制器)**：提供两套控制器——当前平衡车使用 `pid2_t`（对齐 STM32 demo，含 OutOffset 死区补偿 + 微分先行 + Ki=0 自动清零），旧 `pid_t` 保留供参考。
- **`k230_protocol.c` (K230 通讯协议)**：CRC16 帧编解码、状态机解析、TEXT_CMD/TEXT_RESP 远程调试透传。
- **`robot_param.h` (车体运动学)**：集中管理轮径(65mm)、轴距(185mm) 等物理参数，提供 inline 运动学换算函数。

### 2.3 应用逻辑 (App)
- **`app_safety.c` (安全管家)**：小车的"保命系统"。盯着电池电压和倾角，跌倒或低压立刻切断动力。板载 S1 按键可重新启动（Arm）或急停（Disarm）。
- **`app_balance.c` (平衡大脑)**：小车的主循环调度 + 四路 `pid2_t` 控制器：角度环(100Hz)直驱 PWM、速度环(20Hz)→目标倾角、航向角环(20Hz)→差速目标、**差速环(20Hz)→差分 PWM**。
- **`app_circle_demo.c` (圆弧运动)**：串口 `c`/`circle` 触发整圆轨迹运动，三重判停。
- **`app_motor_demo.c` (电机测试)**：独立的测试模式，可在不开启平衡功能的情况下通过串口测试电机。

## 3. 小车是如何运转的？（调度机制）

小车没有使用 RTOS，而是用"时间片轮询"机制。SysTick 每 **1 毫秒** 产生一次心跳：

- **每 1 毫秒 (1000 Hz)**：读取传感器数据缓存，更新编码器计数。
- **每 10 毫秒 (100 Hz)**：**核心控制时刻**。读取姿态快照，安全检测，执行角度环 PID → 直接下发 PWM 到电机。
- **每 50 毫秒 (20 Hz)**：速度环、航向角环、差速环、K230 状态上报、圆弧运动子任务。
- **每 200 毫秒 (5 Hz)**：绿灯心跳翻转；红灯警告。
- **每 1000 毫秒 (1 Hz)**：串口打印状态数据（角度、速度、差速、电池等），K230 心跳发送。

## 4. 平衡控制是怎么实现的？（多级串级 PID）

### 4.1 俯仰控制链（两级）

```
速度环 (20 Hz)     输入：目标速度 vs 实际速度  →  输出：目标倾角
    ↓
角度环 (100 Hz)    输入：目标倾角 vs 实际倾角  →  输出：平均 PWM → 电机
```

速度环告诉小车"你应该倾斜多少度来走路"，角度环告诉电机"赶紧转，保持住这个倾斜度别摔了"。角度环直接输出 PWM（不再经过角速度内环中转）。

### 4.2 横摆控制链（三级）

```
航向角环 (20 Hz)   输入：偏航误差  →  输出：差速目标
    ↓
差速环 (20 Hz)     输入：差速目标 vs 实际差速(RPM)  →  输出：差分 PWM
    ↓
左轮 = 平均PWM + 差分PWM      右轮 = 平均PWM − 差分PWM
```

航向角环决定"需要转多少"，差速环决定"用多大差速力来转"。差速环以 RPM 为量纲，补偿电池电压/地面摩擦变化带来的 PWM→速度映射非线性。

### 4.3 `pid2_t` 控制器特点

当前四路 PID 均使用 `pid2_t`（对齐 STM32 demo）：
- **OutOffset**：死区补偿，突破 TB6612 静摩擦
- **微分先行**：D 项作用于测量值变化，避免遥控指令突变引发尖峰
- **Ki=0 自动清零**：调试期关积分不残留"债务"
