# BSP_BATTERY 电池电压监测模块 学习笔记

## 📖 一、整体概述

### 1.1 这个模块在项目中的位置

本项目是一个**两轮自平衡瞄准小车**，主控为 **TI MSPM0G3507**。

`bsp_battery` 负责监测锂电池电压，在电压过低时通知业务层降功率或停车，保护电池不过放。

```
┌──────────────────────────────────────────────────────────────┐
│                    app_safety.c（业务层）                     │
│  根据 bsp_battery_get_state() 决定是否限幅/停车              │
└────────────────────▲─────────────────────────────────────────┘
                     │
┌────────────────────┴─────────────────────────────────────────┐
│                 bsp_battery.c/h（本模块）                     │
│                                                              │
│  ADC 采样 → 电压换算 → EMA 滤波 → 阈值状态机判断             │
│  100 Hz 周期调用，全程整数运算                                │
└────────────────────▲─────────────────────────────────────────┘
                     │ PB24 引脚（A0_5）
┌────────────────────┴─────────────────────────────────────────┐
│              电阻分压电路 R1(100k) + R2(22k)                 │
│              分压比 K = 22/122 ≈ 0.18                        │
└──────────────────────────────────────────────────────────────┘
```

### 1.2 硬件方案

```
电池正极 ── R1(100kΩ) ──┬── PB24(ADC 引脚) ── R2(22kΩ) ── GND
                         │
                      ADC 测量点

电池电压范围：9.0V~12.6V（3S 锂电）
ADC 引脚电压 = 电池电压 × R2/(R1+R2) = 电池电压 × 0.18
ADC 引脚电压范围：1.62V~2.27V（在 0~3.3V 范围内，安全）
ADC 原始值范围：2010~2820（12 位 ADC，0~4095）
```

## 📋 二、宏/类型/函数汇总

### 2.1 编译期可配宏

| 宏 | 默认值 | 含义 |
|----|--------|------|
| `BSP_BATTERY_ADC_REF_MV` | 3300 | ADC 参考电压（mV），必须与 VDDA 一致 |
| `BSP_BATTERY_ADC_FULL_SCALE` | 4095 | ADC 满量程（12 位） |
| `BSP_BATTERY_DIVIDER_RATIO_X10000` | 1803 | 分压系数 × 10000（定点数） |
| `BSP_BATTERY_EMA_ALPHA_256` | 32 | EMA 滤波系数 × 256 |
| `BSP_BATTERY_WARN_MV` | 9500 | 低压告警阈值（mV） |
| `BSP_BATTERY_STOP_MV` | 9000 | 安全停车阈值（mV） |
| `BSP_BATTERY_HYSTERESIS_MV` | 200 | 状态回滞（mV） |
| `BSP_BATTERY_DISCONNECTED_MV` | 1000 | 断线检测阈值（mV） |

### 2.2 状态枚举

| 状态 | 值 | 含义 |
|------|-----|------|
| `BSP_BATT_STATE_UNKNOWN` | 0 | 上电初始/断线 |
| `BSP_BATT_STATE_NORMAL` | 1 | 电压正常 |
| `BSP_BATT_STATE_LOW_WARN` | 2 | 低压告警 |
| `BSP_BATT_STATE_LOW_STOP` | 3 | 电压过低，立即停车 |

### 2.3 函数汇总

| 函数名 | 功能 | 调用频率 |
|--------|------|---------|
| `bsp_battery_init()` | 初始化 + 触发首次转换 | 一次 |
| `bsp_battery_update()` ⭐ | 采样→换算→滤波→判断 | 100 Hz |
| `bsp_battery_get_mv()` | 获取滤波后电压 | 任意 |
| `bsp_battery_get_raw()` | 获取最近一次 ADC 原始值 | 调试 |
| `bsp_battery_get_state()` | 获取当前状态 | 任意 |
| `bsp_battery_raw_to_mv()` | ADC 原始值→电池电压（纯函数） | 任意 |

## 🔄 三、核心逻辑

### 3.1 采样流程

```
bsp_battery_update() 每 10 ms 调用一次：
  1. wait_conversion_done()    ← 轮询等待 ADC 转换完成（< 5 µs）
  2. 读取 MEM0 寄存器          ← 获取 ADC 原始值（0~4095）
  3. bsp_battery_raw_to_mv()   ← 换算为电池毫伏
  4. EMA 滤波                  ← 整数 EMA，α=0.125
  5. classify()                ← 阈值状态机判断
  6. trigger_conversion()      ← 触发下一拍转换
```

### 3.2 电压换算公式

```
第 1 步：ADC 原始值 → 引脚电压（mV）
  mv_pin = raw × 3300 / 4095

第 2 步：引脚电压 → 电池电压（mV）
  v_bat = mv_pin × 10000 / 1803
        = mv_pin × 5.545

示例：raw=2000
  mv_pin = 2000 × 3300 / 4095 = 1612 mV
  v_bat  = 1612 × 10000 / 1803 = 8940 mV
```

### 3.3 EMA 整数滤波

```
公式：ema = (α × new + (256-α) × old + 128) >> 8

α = 32，α/256 = 0.125
时间常数 ≈ 8 拍 = 80 ms @ 100 Hz

示例：old=10000, new=10100
  ema = (32×10100 + 224×10000 + 128) >> 8
      = (323200 + 2240000 + 128) >> 8
      = 2563328 >> 8
      = 10013
```

### 3.4 状态转换图

```
                    ┌──────────┐
                    │ UNKNOWN  │ ← 上电/断线
                    └────┬─────┘
                         │ mv > 1000
                         ▼
┌──────────┐  mv ≤ 9500  ┌──────────┐  mv ≤ 9000  ┌──────────┐
│  NORMAL  │ ──────────→ │ LOW_WARN │ ──────────→ │ LOW_STOP │
│          │ ←────────── │          │ ←────────── │          │
└──────────┘  mv ≥ 9700  └──────────┘  mv ≥ 9200  └──────────┘
```

注意回滞：离开 LOW_WARN 需要电压回升到 9700（WARN+200），不是回到 9500。

### 3.5 断线检测

```
电池未接时的行为：
  PB24 浮空 → ADC 读数 ≈ 0 → 换算 ≈ 0 mV
  旧版 classify() → 判为 LOW_STOP → 触发紧急停车

修复后：
  mv < 1000 → 返回 UNKNOWN → 不触发任何保护
  接上电池后（哪怕快没电了 9V）→ 跨越阈值 → 正常分类
```

## 🧩 四、关键代码段

### 4.1 轮询中断标志

```c
DL_ADC12_getRawInterruptStatus(ADC_BAT_INST,
    DL_ADC12_INTERRUPT_MEM0_RESULT_LOADED)
```

"Raw Interrupt Status"（原始中断状态）是硬件寄存器的一个位，它在 ADC 转换完成时被硬件自动置 1。即使没有使能 NVIC 中断，这个位也可以被轮询读取。这叫做"把中断标志当作状态位来查询"。

### 4.2 定点数分压系数

```c
#define BSP_BATTERY_DIVIDER_RATIO_X10000 (1803)
```

为什么不直接用 `0.1803`？因为浮点运算在 Cortex-M0+ 上很慢。

为什么放大 10000 倍？因为分压比约 0.18033，四个有效位，10000 倍正好把精度保留到整数。

### 4.3 首拍特殊处理

```c
if (s_batt.primed == 0u) {
    s_batt.ema_mv = mv_now;   // 首拍跳过滤波
    s_batt.primed = 1u;
}
```

没有这个处理：EMA 从 0 开始，要很多拍才能爬到真实电压→这段时间误判为 LOW_STOP。

有这个处理：第一拍直接跳到真实电压→状态判断正确。

## 🐛 五、常见踩坑

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 电压读数一直 0 | 忘记调用 `bsp_battery_update()` | 在主循环中添加 100 Hz 调用 |
| 电压读数不准 | 分压电阻值与宏定义不匹配 | 测量实际 R1/R2，修改 `DIVIDER_RATIO_X10000` |
| 状态反复跳变 | 回滞不够或采样率太低 | 确认 HYS=200，采样率 100 Hz |
| 断电后重新上电报警 | 电池低于 WARN 阈值 | 电池正常，充电即可 |
| 不接电池时误判 STOP | 旧版没有断线检测 | 确认 DISCONNECTED_MV=1000 宏已生效 |
